# راهنمای توسعهٔ Sahne ProMax ۲.۷.۰

این پروژه یک برنامهٔ دسکتاپ ویندوز برای الرت‌های استریم است. سرور HTTP محلی آن با ماژول‌های داخلی Node.js کار می‌کند؛ Electron و ابزارهای ساخت فقط وابستگی توسعه هستند. راهنمای کاربران در [README فارسی](README-FA.md) و جزئیات جریان داده در [DATA_FLOW](DATA_FLOW.md) آمده است.

## اجرا و بررسی

```bash
npm ci                 # نصب وابستگی‌های توسعه از فایل قفل
npm test               # آزمون‌های سرور، کنترلر، اوورلی و انتشار
npm run format:check   # بررسی قالب کد
npm start              # اجرای برنامه در حالت توسعه
npm run dist           # ساخت نصب‌کنندهٔ ویندوز در dist/
```

برای اجرای آزمایشی بدون دست‌زدن به داده‌های اصلی، متغیر محیطی `SAHNE_PLUS_DATA_DIR` را به یک پوشهٔ موقت تنظیم کنید. پورت پیش‌فرض ۷۷۸۸ است و در فایل تنظیمات همان پوشه ذخیره می‌شود. اسکریپت `npm run screenshots -- [outDir] [port]` از نمونهٔ در حال اجرا روی پورت انتخابی عکس می‌گیرد.

## نقشهٔ کد

| مسیر | مسئولیت |
| --- | --- |
| `electron/main.js` و `electron/updater.js` | پنجره، Tray، حافظهٔ امن و به‌روزرسانی |
| `server/index.js` | ساخت سرور و اتصال ماژول‌ها |
| `server/integrations/` | KickBot، Kick، StreamElements، Donofa و Meld |
| `server/playback/` | صف، کپچر دونیت، انتخاب رسانه و ذخیرهٔ الرت منتظر |
| `server/config/` و `server/features/` | تنظیمات، تاریخچه، آمار، هدف و پشتیبان‌گیری |
| `server/http/` | API محلی، فایل‌ها و محدودیت‌های امنیتی |
| `public/` | کنترلر، اوورلی و ویجت‌های OBS |
| `test/` | آزمون‌های خودکار |

داده‌ها به‌صورت پیش‌فرض در `Documents\Sahne Plus` می‌مانند و با حذف برنامه پاک نمی‌شوند. برای تست ارائه‌دهنده‌ها، از حساب و کلید آزمایشی خودتان استفاده کنید و آن‌ها را وارد مخزن نکنید.
